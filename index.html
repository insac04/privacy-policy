개인정보처리방침

시행일: 2026-04-22

운수떼기(이하 "앱")는 이용자의 개인정보를 중요하게 생각하며, 관련 법령을 준수하기 위해 다음과 같이 개인정보처리방침을 안내합니다.

앱은 네트워크 연결 없이 기기 내부에서만 동작하는 100% 로컬 실행 앱입니다. 모든 게임 기능, 설정 저장, 기록 저장, 배경 이미지 적용은 이용자 기기 내부에서 처리되며, 외부 서버와 통신하지 않습니다.

1. 개인정보 수집 여부

다만, 앱 기능 제공을 위해 아래와 같은 정보가 기기 내부에 저장될 수 있습니다.

  • 앱 이용 설정 정보
  • 게임 진행 및 기록 정보
  • 이용자가 선택한 배경 이미지

위 정보는 이용자 기기 내부에만 저장되며, 앱은 외부 서버로 정보를 전송하지 않습니다.

2. 수집 및 이용 목적

앱은 다음 목적에 한해 정보를 처리합니다.

  • 앱 설정 저장 및 복원
  • 게임 진행 상태 및 플레이 기록 유지
  • 맞춤형 배경 이미지 적용
  • 게임 오디오, 효과, UI 옵션 유지

3. 수집하는 항목 및 처리 방식

3-1. 기기 내부 저장 정보

앱은 설정값과 플레이 기록을 이용자 기기 내부에 저장할 수 있습니다.

저장 예시는 다음과 같습니다.

  • 앱 환경설정
  • 게임 기록
  • 게임 편의 기능 관련 설정

3-2. 사진(갤러리) 접근

앱은 이용자가 홈 화면 배경 이미지를 직접 선택하는 경우에만 기기의 사진 또는 갤러리 접근 기능을 사용할 수 있습니다.

이 경우:

  • 이용자가 선택한 이미지 파일을 읽어 앱 배경으로 사용합니다.
  • 선택된 이미지는 앱 내부에 저장되어 이후 다시 사용할 수 있습니다.
  • 해당 이미지는 외부 서버로 전송되지 않습니다.

이 기능은 선택 사항이며, 이용자가 사용하지 않으면 사진 접근이 필요하지 않습니다.

4. 개인정보의 제3자 제공

앱은 이용자의 정보를 제3자에게 판매하거나 제공하지 않습니다.

앱은 외부 서버에 이용자 정보를 보관하지 않으며, 제3자에게 전달할 개인정보를 별도로 수집하거나 보유하지 않습니다.

5. 개인정보의 처리 위탁

앱은 별도의 클라우드 서버, 회원 서버, 분석 서버, 광고 서버를 사용하지 않으며, 이용자 정보를 외부 사업자에게 처리 위탁하지 않습니다.

6. 개인정보의 보유 및 이용기간

앱이 저장하는 정보는 다음과 같이 처리됩니다.

  • 설정 정보: 이용자가 앱을 삭제하거나 앱 데이터 삭제 전까지
  • 플레이 기록: 이용자가 앱을 삭제하거나 앱 데이터 삭제 전까지
  • 사용자 지정 배경 이미지: 이용자가 배경 이미지를 변경하거나 앱을 삭제하거나 앱 데이터 삭제 전까지

이용자가 앱을 삭제하거나 앱 데이터를 삭제하면 관련 정보는 함께 삭제될 수 있습니다.

7. 개인정보처리방침의 변경

본 개인정보처리방침은 앱 기능 변경, 법령 변경 또는 운영 정책 변경에 따라 수정될 수 있습니다.

내용이 변경되는 경우 앱 설명 페이지, 배포 페이지 또는 별도 고지 수단을 통해 안내할 수 있습니다.
